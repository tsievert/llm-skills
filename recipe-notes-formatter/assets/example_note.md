# Tomaattinen linssikeitto
[[000 Cookbook index|Cookbook index]]

> [!note]
> Tarjoile tuoreen leivan kera.

## Ingredients
#ingredients
- [x] 1 sipuli
- [x] 2 valkosipulinkynttä
- [x] 1/4 tl jauhettua korianteria
- [x] 1,5 dl punaisia linssejä
- [x] 2 dl kookosmaitoa
- [x] (1 rkl currytahnaa)
- [x] mustapippuria

---

## Directions
1. Silppua sipuli ja valkosipuli. Kuullota hetki.
2. Lisää tomaattimurska, vesi ja linssit. Keitä, kunnes linssit ovat kypsiä.
3. Soseuta tasaiseksi sauvasekoittimella.
